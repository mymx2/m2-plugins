# 商业化策略（GTM）

产品商业化、上市策略、定价、渠道、PMF 验证时加载。GTM 的输入是已定义的产品（PRD）和已排定的优先级，输出是"怎么卖、卖给谁、怎么知道成了"的可执行策略。

## 产品定位

### 定位三角

先把三件事钉死再谈策略，缺一件整个 GTM 都是空中楼阁：

| 要素         | 提炼方法                           | 检验标准                   |
| ------------ | ---------------------------------- | -------------------------- |
| 目标用户     | 用户调研 + 市场细分（TAM/SAM/SOM） | 可描述、可触达、有付费意愿 |
| 核心价值主张 | 痛点访谈 + 价值阶梯                | 用户是否愿意为此付费       |
| 差异化优势   | 竞品功能/价格/体验对比             | 优势可持续、可被用户感知   |

输出格式：目标用户（具体人群画像）+ 一句话价值主张 + 与最强替代方案的差异对比（连同比值，如"同等品质价格降 40%"）。

### 竞品定位图

选目标用户最关心的两个维度建坐标（价格-性能、便利-专业等），把直接竞品和间接替代都标上去（1-10 评分），找竞争稀疏但需求存在的空白区作为切入位。挤在竞品堆里的定位需要额外理由。

## 定价

### 定价方法五选（说明选了哪个、为什么）

| 方法     | 核心逻辑                          | 适用场景                       | 风险                   |
| -------- | --------------------------------- | ------------------------------ | ---------------------- |
| 成本加成 | 成本 × (1+目标毛利率)             | 成本清晰、竞争不激烈、同质化高 | 忽视市场承受力         |
| 竞品参照 | 竞品价 ± 差异价值折算             | 成熟市场、差异化小、价格敏感   | 易陷价格战             |
| 价值定价 | 用户获得价值 × 分成比例（10-30%） | 创新产品、价值可量化、B 端     | 价值量化难             |
| 渗透定价 | 低价快速占市场                    | 网络效应明显、平台型、规模经济 | 资金压力大、盈利周期长 |
| 撇脂定价 | 支付意愿上限                      | 技术领先、专利保护、早期市场   | 吸引竞争者进入         |

### 定价结构

- **版本分层**：免费/基础版降门槛获线索，专业版做主力收入对标竞品，企业版高客单价按需报价。
- **计费模式**：一次性（需设计升级维护收费路径）/ 订阅（年付折扣降流失）/ 用量（阶梯定价）/ 交易抽成（平台型，保障流动性）/ Freemium（免费足够有吸引力、付费足够有价值）。

## 渠道

按产品类型选组合，说明选择原因：企业软件 → 直销+代理+PLG；消费硬件 → 电商+线下+众筹首发；快消 → 电商+新零售+分销；工业 B2B → 直销+展会+垂直平台；移动应用 → 商店+社媒+KOL。

首发渠道四标准：用户密度高、验证成本低、反馈速度快、资源可控。集中 80% 资源在 1-2 个首发渠道，4-8 周内完成 PMF 初步验证，预设不达标就切换的退出机制。扩张节奏：0-6 月深耕首发（看 CAC 回收周期、单渠道月新增）→ 6-12 月验证 1-2 个扩展渠道（看渠道 ROI 对比）→ 12 月+ 多渠道并行（看全渠道 CAC、渠道冲突率）。

## 种子用户

画像五维：创新者属性（容忍不完美）、痛点强度（愿意付费解决）、影响力（圈内有话语权）、反馈意愿（愿意共创）、数据价值（行为数据可指导迭代）。

获取六法按场景选：垂直社区深耕（小众专业）/ KOL-KOC 合作（消费品）/ 推荐计划双向奖励（有社交属性）/ 行业活动展会（B2B）/ 冷启动定向名单（企业级）/ 内容营销（专业型长尾）。

## PMF 验证（商业化是否成立的判决）

定性 + 定量两组指标都达标才算 PMF，单项好看不算：

**定性**：Sean Ellis 测试（"明天不能用了你什么感受"，≥40% 选"非常失望"）或 NPS ≥50；用户自发推荐率 ≥30%。

**定量**：

| 指标           | 健康基准                   |
| -------------- | -------------------------- |
| D1 / D7 留存   | ≥40% / ≥20%                |
| D30 留存       | 消费类 ≥20%，B2B SaaS ≥60% |
| 核心功能使用率 | ≥60%                       |
| 试用转付费     | SaaS ≥15%                  |
| 付费续费率     | ≥80%                       |
| LTV/CAC        | ≥3，且回收周期 ≤12 个月    |

综合判决格式：定性过 / 留存健康 / 转化健康 / 经济模型健康，四项各打勾后给结论——已达 PMF / 接近（需优化什么）/ 未达（需调整什么）。**未达 PMF 不扩渠道不加预算**，先回去调产品或定位。

## 红线

- 定位三角缺一件不做 GTM：没有可触达的目标用户、没有用户愿付费的价值主张、没有可感知的差异，策略写得再细也是空转。
- 定价不许只报一个数：必须说明用了五种方法里的哪种、版本怎么分层、计费模式是什么。
- PMF 未验证前不做增长动作（扩渠道、加预算、铺量），那是把没验证的东西卖得更快。
