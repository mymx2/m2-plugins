# 发现：脑暴、反馈分析、竞品分析

产品创意发散、用户反馈分析、产品/市场竞品分析时加载。技术选型对比（选哪个库、哪个工具）走 learn 技能，不在此列。

## 脑暴模式

### 先聚焦问题

发散之前先确认五件事（缺什么问什么）：谁有这个问题、现在怎么解决的、不解决会怎样、什么算成功、有什么约束。然后把问题重述为 How-Might-We："我们如何能让[目标用户]在[场景]中更轻松地[完成目标]？"在模糊问题上做脑暴，只会规模化地产出模糊创意。

### 用框架发散（选 2-3 个，说明选了哪些）

- **SCAMPER**：替换 / 组合 / 调整 / 修改 / 另作他用 / 消除 / 重排——每个视角 1-2 个想法，共 7-14 个。
- **5Why 分叉**：逐层问为什么；一层有两个答案就两个分支都追；每层产出一个可发散的根因候选。
- **反向脑暴**：先问"怎么才能让这事更糟？"，再把每个答案逆转。
- **约束翻转**：每次抽掉一个默认约束（预算、延迟、平台），问这时问题长什么样。
- **HMW 多角度**：对最强机会点，从多个角度生成卡片——核心动作、障碍移除、情境扩展、价值升级、协作维度、极端用户。

### 缺用户洞察时先共情（可选前置）

如果脑暴卡在"不知道用户真正要什么"，先补共情再发散，不要对着空想脑暴。两张图：

**共情地图**（Says/Thinks/Does/Feels/Pains/Gains 六格）：Says 记用户原话，Thinks 写没说出口的内心独白，Does 记可观察行为，Feels 写情绪，然后归纳痛点（想消除的）和收益（想获得的）。素材来自用户反馈、评论、访谈记录——没有一手素材时，反馈分析模式的产出就是输入。

**POV 陈述**（把洞察变成设计挑战）：`[用户群体] 需要 [核心需求] 因为 [深层洞察]`。五项质检：用户群体具体可识别、需求聚焦不宽泛、洞察基于真实观察不是假设、陈述里不含解决方案、聚焦到足以激发创意但不过度限制。POV 过关后再进 HMW 和发散框架。

### 收敛

把幸存的创意按 prioritization-frameworks reference 的影响 × 工作量四象限打标。输出筛过的创意清单，每条带一句话理由和象限位置——可以直接喂给 prioritization-frameworks reference，不是原始堆积。

## 反馈分析模式

### 规模分支

- ≤20 条：精读模式，逐条解读。
- \>20 条：统计模式——先清洗（去完全重复、合并相似度 >90% 的并标合并数、<5 字无实质内容的单独统计不做深析），再分类。

### 分类与情感

六大类：功能需求（想要但没有）、Bug（有但异常）、使用咨询（找不到/不会用）、体验吐槽（有但难用）、正面评价、其他。一条可归多类时标主分类+次分类。

情感逐条标注并校准：陈述事实的好评（"功能可用"）判中性不判正面；"希望能支持XX"是中性；"为什么还不支持XX"是负面。

### 痛点排序与三角验证

痛点按 `频次 × 严重度 × 用户权重 × 可信度` 排序。一个痛点要标"已验证"必须过三角验证：跨方法（不同证据类型）、跨独立来源、或跨时间出现。单渠道的说法保持为假设。

收尾给：Top N 痛点及得分、好评告诉你要守住什么、排序后的改进候选——喂给 prioritization-frameworks reference。

## 竞品分析模式

### 目的分支（说明选了哪个）

| 分析目的 | 侧重                | 产出                                |
| -------- | ------------------- | ----------------------------------- |
| 产品设计 | 功能矩阵 + 交互体验 | 差异化功能清单，2-3 页              |
| 融资 BP  | 市场格局 + 壁垒     | 格局图 + 壁垒分析，1 页             |
| 战略规划 | 全维度              | SWOT + 五力 + 定价 + 路线图，5-8 页 |
| 年度汇报 | 份额变化 + 趋势     | 同比变化 + 趋势判断                 |

### 收集，带可信度标注

维度：基本面（成立时间、融资、团队、用户量）、产品（核心功能、最近更新、路线图）、定价（套餐、区间、免费版限制）、口碑（好评点、差评点）、策略（目标市场、获客渠道、合作伙伴）。每格标可信度：高（官网/定价页/官方公告）、中（媒体、评论、行业报告）、低（传言、过期，标 `[待核实]`）。整个收集标注时效（"基于 2026 年 Q3 公开信息"）。

### 分析

- **功能对比矩阵**：所有竞品用同一组维度；自由形式的逐家笔记无法横向读。
- **SWOT**：内部 S/W + 外部 O/T，再交叉成策略：SO（发挥）、WO（补强）、ST（防御）、WT（规避）。
- **Porter 五力**：供应商议价力、买家议价力、新进入者、替代品、现有竞争——每项评强/中/弱附一句话理由，最后给行业整体吸引力判断。
- **定位**：把竞品放到最重要的两个维度上（如价格 × 深度），点名象限空白。

### 三层结论（必收尾）

每份竞品报告以三层收尾：**追平**——领先者划出的及格线，必须达到；**差异**——有意分叉的点；**创新**——市场空白处可以跳过去的点。停在功能矩阵的报告只做了一半。
